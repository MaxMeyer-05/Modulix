# Modulix - Reverse Proxy

Reverse proxy management library for the Modulix framework.

## setup

To use the Modulix Reverse Proxy library, add the following package reference to your project:

```xml
<PackageReference Include="Modulix.ReverseProxy" Version="1.0.1" />
```
